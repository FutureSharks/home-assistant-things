# Device Offline Alert

Sends a Home Assistant Companion app notification when a device has been unreachable for a set time, and optionally when it comes back online. The recovery notification replaces the offline one on the phone.

Works with any device whose entities become `unavailable` when Home Assistant can't reach it, such as Reolink cameras and Zigbee, Z-Wave or Wi-Fi devices. Pick one entity per device, for example a Reolink camera's main stream entity.
